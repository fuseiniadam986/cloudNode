# 下一阶段

## 已补齐的部署基础

1. 安装脚本自动安装基础依赖
2. 未检测到 Xray 时自动安装 Xray-core
3. 可选 `ENABLE_BBR=1` 启用 BBR
4. 可选 `DOMAIN` + `EMAIL` 安装 Caddy 并自动申请 HTTPS 证书
5. 提供 `status`、`diagnose`、`backup`、`uninstall` 命令
6. README 与部署文档补齐公开项目说明
7. 节点编辑、启停、链接、二维码和订阅接口
8. 面板日志查看和配置备份接口
9. 多协议一键生成
10. REALITY 密钥、shortId 和链接生成
11. 二维码刷新
12. Xray Stats API 流量统计
13. 面板内 BBR 系统优化
14. 安装脚本升级与回滚
